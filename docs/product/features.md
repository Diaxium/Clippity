# Features

## Capture

- **Region & Window capture** — precise selection via a transparent overlay,
  plus one-shot window capture.
- **Custom modes** — Freehand, Multi-Area, Color Picker, Palette Capture,
  Grab Text (OCR via native Windows OCR), Scrolling Window (auto-scroll +
  stitch).
- **Countdown HUD** — a taskbar-edge timer strip before a delayed capture.
- **Presets** — save and reuse capture configurations.

## Organize

- **Library** — browse, group, and manage past captures with fast thumbnails.
- **Tags, favorites, and collections** — label captures and arrange them into
  named, ordered sets.
- **Aux catalog** — dedicated entries for sampled colors, palettes, and
  grabbed text.

## Edit

- **Layered editor** — shapes, text, blur, and a magnifier sample region.
- **Effects** — inner/outer shadow with spread, per-node blend modes.
- **Non-destructive** — live node editing; save flattened or as an editable
  scene.

## System integration

- **System tray** with a quick flyout of recent captures.
- **Global shortcuts**, native dialogs, and clipboard access.
- **Transparent, vibrancy-backed windows** (Win11 Mica) for a native look.
- **First-launch onboarding** and live, hot-applied settings.
